# Before public release

- Confirm authorship and institutional permission to release these source files and derived encoder measurements.
- Choose a license; none has been imposed in this draft.
- Confirm whether the submission requires an anonymous repository. Remove identities and inspect Git metadata accordingly.
- Reconcile manuscript equations, link dimensions and certificate assumptions with the exact released source revision. The included default planar model is 0.30, 0.25, 0.15 metres.
- Review tests, recorded results, source hashes and known limitations. Runtime invariants are not physical collision guarantees.
- Supply a valid citation after title, author list and publication status are settled.
- Inspect staged files for secrets, personal data and third-party materials.
- Create a GitHub remote and push only when explicitly authorized.

No credentials, robot IP addresses, SSH logs, lab photographs, vendor packages or pretrained weights are included by design.
